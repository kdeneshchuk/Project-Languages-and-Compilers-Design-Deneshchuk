8. WHAT I UNDERSTOOD
======================================================================
The loop goes back to the condition after each iteration, so it can check if it should run again. In a `for` loop, 
the program checks if the variable has reached the last value before adding 1, to avoid overflow. The optimizer counts 
how many times each variable is used. It uses the symbol instead of the name because two different variables can have 
the same name. A task is not inlined if its `give` is inside a `when`, because it could stop the function in the middle
and cause problems with the rest of the code.
