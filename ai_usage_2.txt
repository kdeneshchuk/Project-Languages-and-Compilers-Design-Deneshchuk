9. WHAT I UNDERSTOOD
======================================================================
The compiler has three parts. First the parser checks if the code is written correctly and makes a tree. 
With `--ast` I can see this tree. Then the semantic part checks things like types, names and if a variable can be changed. 
After that the code generator makes LLVM IR.

For `x of center of c`, the compiler finds `c`, then `center`, then `x`. To change `x`, all parts of this chain must be 
mutable. A member function gets the object it works with, so it can change that object.

I used `llvmlite` for the IR. `when` makes branches, `give` returns a value, and `read` and `print` use `scanf` and `printf`. 
The tests compile and run the programs, and compare what they print with the expected output.
